K. SEARCH
----------------------------------------------------------------
PostgreSQL FTS (GIN tsvector) + pg_trgm + an alef-less skeleton index, so the
Uthmani spelling and the plain spelling return the same hits. Stored text is
never normalised — only derived columns are. Exact phrase, partial, filtered,
empty and no-result searches are all covered by tests; injection attempts return
0 rows and leave the dataset unchanged.

dataset version.
