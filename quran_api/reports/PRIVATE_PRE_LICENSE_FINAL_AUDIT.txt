  · loadEnv() forces publicDataEnabled / publicApiEnabled /
    dataRedistributionAllowed to false whenever PRIVATE_MODE is on — setting
    them to true in the environment changes nothing (test: "loadEnv cannot be
    talked into a public posture while private").
  · the server binds 127.0.0.1 by default in private mode (test).
  · createApp() REFUSES to start a public instance whose licences are not
    confirmed (test: "refuses to start a public instance without the matching
    licences").
  · content endpoints answer 451 to anonymous callers with a PRIVATE_MODE
    message; only an authenticated internal caller reads (test).
  · the PWA ships `noindex, nofollow, noarchive` and a Disallow-all robots.txt.
  · Flutter staging/production configs carry an EMPTY base URL, guarded by a
    test, so no build can point at a public host by accident.
