BUGS FOUND BY RUNNING THIS IMPORT (all fixed in this commit)
  1. The parser skipped page markers that sat INSIDE a hadith, so every record
     after a mid-hadith page break claimed the previous page. Caught by checking
     records against the source file: 122/300 page mismatches → now 0/15,961.
     Regression test: tests/shamela-adapter.test.ts.
  2. Book ordering used a per-file counter that restarted in every volume, so
     all 67 books came out as order_number=1. Now ordering follows the number
     the edition itself prints (كتاب الوحي 1 … 67).
  3. Search ran an OR-chain that scanned all 15,961 rows and re-normalized the
     text of each one (2.1-2.4 s). Replaced with an indexed UNION (0.003-0.34 s),
     same result counts verified before and after (الصلاة → 2,129 both times).
