# SPEC — بناء فلاح Flutter (المرحلة M1+ وفق flutter-autobuild)

## الجملة الواحدة
منصة لصانع المحتوى الإسلامي تتيح قراءة القرآن الموثق والبحث فيه والذكر اليومي،
تمهيدًا لنقل كامل مزايا الـPWA (المرجع الحي حتى M4).

## قرارات المكدس (توجيهات المستودع تسبق افتراضات المهارات)
- المنصات: Android + Web (iOS لاحقًا بجهاز Mac).
- اللغة: عربية أولًا RTL + إنجليزية، تبديل وقت التشغيل. ARB جاهزة (359 مفتاحًا).
- الخلفية: Supabase (قرار ADR-002؛ المخطط 34 جدولًا جاهز) — التشغيل الحي بعد مفاتيح المالك.
- الحالة: Riverpod. التوجيه: go_router بـ StatefulShellRoute.
- التخزين المحلي: shared_preferences (إعدادات/عدادات)؛ drift يُقيَّم عند المزامنة.
- الثيم: ثوابت Tokens المنقولة (ورق قديم/جلد) — **لا** ColorScheme.fromSeed.
- الخط: Cairo/Amiri مدمجة (منجز).
- البيانات المقدسة: quran-json@3.1.2 (نفس مصدر الـPWA حرفيًا؛ بصمات متطابقة عبر المنصتين)
  أصولًا مدمجة `assets/quran/` — SOURCE_LOCK يلف كل نص عند التقديم.

## الشاشات (M1)
1. الصدفة: تنقل سفلي أربع وجهات (الرئيسية، القرآن، السبحة، الإعدادات).
2. الرئيسية: تحية + آية اليوم (اختيار حتمي باليوم من البيانات الموثقة) + بطاقات تنقل.
3. قائمة السور: 114 سورة (الاسم، النوع، عدد الآيات) مع بحث فوري بالاسم.
4. قارئ السورة: آيات مرقمة ﴿n﴾ بخط AmiriQuran، شارة «موثق»، ترجمة اختيارية.
5. البحث: مرجع (2:255) أو نص منسق عربيًا (تطبيع منقول من الـPWA) مع إبراز النتيجة.
6. السبحة: عداد بأهداف 33/34/100 + إجمالي يومي محفوظ.
7. الإعدادات: المظهر (فاتح/داكن/نظام) واللغة، حالتهما محفوظتان.

## نموذج البيانات المحلي
- أصول: `assets/quran/index.json` + `assets/quran/en/<1..114>.json` (نص عثماني + ترجمة صحيح).
- ‏kv ‏(shared_preferences): `settings.themeMode`, `settings.locale`,
  `tasbih.total.<yyyy-mm-dd>`, `tasbih.target`.
- الخادم لاحقًا: مخطط `supabase/migrations` القائم كما هو.
