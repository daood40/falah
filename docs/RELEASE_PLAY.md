## 2) خطوات المالك (مرة واحدة)

1. **حساب مطور Google Play** — ‏play.google.com/console، رسوم 25$،
   وتحقق هوية. ملاحظة: الحسابات الشخصية الجديدة يلزمها اختبار مغلق
   (12 مختبِرًا لمدة 14 يومًا) قبل الإنتاج — ابدأ بمسار Internal testing.
2. **مفتاح التوقيع** (على جهازك، واحتفظ بنسخة آمنة — فقدانه يمنع التحديثات):
   ```
   keytool -genkey -v -keystore upload-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   base64 -w0 upload-keystore.jks   # انسخ الناتج
   ```
3. **أسرار المستودع** — ‏GitHub → Settings → Secrets and variables → Actions:
   `KEYSTORE_BASE64` (ناتج base64) · `STORE_PASSWORD` · `KEY_PASSWORD` ·
   `KEY_ALIAS` (=`upload`).
4. **البناء**: شغّل workflow ‏«Android Release (AAB)» يدويًا (Run workflow)
   أو ادفع وسم `v2.2.0`. حمّل `falah-release-aab` من Artifacts.
5. **الرفع**: ‏Play Console → Create app → املأ النماذج أدناه → Internal
   testing → ارفع الـAAB → بعد اكتمال متطلب الاختبار المغلق روّج للإنتاج
   بإطلاق متدرج 20%.

## 3) بطاقة المتجر (انسخ كما هي)

- **الاسم** (≤30): `فلاح — محتوى إسلامي موثوق`
- **الوصف القصير** (≤80):
  `صمّم آيات وأحاديث موثقة، اقرأ القرآن، سبّح واذكر — بلا إعلانات وبلا إنترنت`
- **الوصف الكامل** (≤4000):

  ```
  فلاح منصة صانع المحتوى الإسلامي الموثوق: صمّم منشورات آيات وأحاديث
  بمصادرها، واقرأ وابحث في القرآن الكريم كاملًا دون إنترنت.

  ✦ قرآن كامل (نص عثماني موثق من Tanzil) مع بحث بالنص أو بالمرجع (٢:٢٥٥)
  ✦ أحاديث بمصادرها ودرجاتها — لا نعرض نصًا شرعيًا بلا توثيق أبدًا
  ✦ محرر تصميم عربي: خطوط، ألوان، طبقات، تصدير صور عالية الجودة
  ✦ قوالب جاهزة لمنشورات آية اليوم وحديث اليوم والمناسبات
  ✦ فيديوهات آيات متحركة بأربع مقاسات للمنصات
  ✦ سبحة إلكترونية وأذكار قرآنية وورد يومي — يعمل كله دون إنترنت
  ✦ مكتبة أعمالك: مسودات، نسخ، مفضلة، نسخ احتياطي واستعادة
  ✦ وضع ليلي «جلد قديم» ونهاري «ورق قديم» بخطوط عربية أصيلة

  خصوصية كاملة: لا إعلانات، لا تتبع، لا حسابات إلزامية؛ بياناتك تبقى
  على جهازك. النصوص الشرعية لا تُعدَّل أبدًا (قاعدة SOURCE LOCK)،
  والتطبيق لا يقرر أحكامًا شرعية.
  ```
- **الفئة**: Lifestyle (أو Books & Reference) · **مجانًا** · بلا إعلانات
- **البريد**: daoodalfsye@gmail.com ·
  **سياسة الخصوصية**: `https://daood40.github.io/falah/privacy.html`

## 4) نموذج أمان البيانات (Data safety) — أجب هكذا

- Does your app collect or share any of the required user data types? → **No**
- Is all of the user data collected by your app encrypted in transit? → لا يظهر
  (لا جمع بيانات)
- Do you provide a way for users to request that their data is deleted? →
  التطبيق يوفر «مسح البيانات» محليًا؛ لا بيانات على خوادم.
- (صحيح واقعيًا: لا حسابات خادم، لا تحليلات، لا إعلانات — كل شيء محلي.)
- ⚠️ عند تفعيل مزامنة Supabase لاحقًا يجب تحديث هذا النموذج وسياسة
  الخصوصية **قبل** إصدار يحويها، وإضافة حذف حساب داخل التطبيق ورابط حذف.

## 5) تقييم المحتوى (Content rating)

استبيان IARC: صنف «Reference/Utility». أجب «لا» على كل أسئلة العنف
والمحتوى الجنسي والمقامرة والمواد المحظورة ومشاركة الموقع وشراء داخل
التطبيق والتفاعل بين المستخدمين → النتيجة المتوقعة: ‏3+/Everyone.

- Target audience: ‏18 فأكثر أو «كل الأعمار» — اختر 13+ لتجنب متطلبات
  سياسة العائلات الإضافية، فالتطبيق ليس موجهًا للأطفال.
- App access: التطبيق كامل الوظائف دون تسجيل دخول → ‏«All functionality is
  available without special access».
- Ads: ‏No ads.

## 6) iOS (مؤجل)

يلزم حساب Apple Developer ‏(99$/سنة) وجهاز Mac أو CI بـmacOS. الخطة في
MIGRATION.md (M4)؛ عند توفر الحساب نجهّز TestFlight بنفس الأسلوب.

## 7) لماذا لن يُرفض

- سياسة خصوصية عامة مطابقة للواقع + نموذج أمان بيانات صادق (أشهر سبب رفض).
- أذونات دنيا (INTERNET فقط) — لا أذونات بلا مبرر.
- لا تسجيل دخول إلزامي → لا حاجة لحساب مراجعين.
- ‏targetSdk 36 أحدث من المطلوب، AAB موقّع، لا إعلانات، لا شراء داخلي.
- محتوى ديني مرجعي محايد لا يقرر أحكامًا — متوافق مع سياسات المحتوى.
- التطبيق كامل الوظائف دون إنترنت — لا شاشات فارغة ولا أزرار معطلة
  (مثبت بفحص sweep الدائم واختبارات 75+29).
