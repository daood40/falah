# 0001 — SOURCE LOCK: لا نص ديني بلا مصدر موثّق

- التاريخ: 2026-08-29
- الحالة: مقبول

## السياق
فلاح يعرض ويصدّر نصوصًا دينية (قرآن، حديث، تفسير). أي خطأ أو تأليف آلي
في هذه النصوص خطأ جسيم لا يُحتمل، خاصة مع وجود مساعد ذكاء اصطناعي في التطبيق.

## القرار
كل نص ديني يمر عبر طبقة `src/core/sourcelock/` التي تلزمه بمصدر موثّق
(بيانات المصدر كاملة + بصمة تحقق) قبل العرض أو التصدير. الذكاء الاصطناعي
لا يؤلف نصوصًا دينية أبدًا؛ دوره مقصور على التصميم والأفكار والتنظيم.

## البدائل
- الاعتماد على مراجعة بشرية فقط: مرفوض — لا يمنع الخطأ برمجيًا ولا يتوسع.
- السماح للنموذج بالاقتباس مع تحذير: مرفوض — لا ضمان لدقة الاقتباس.
