# DATA_PROVENANCE — من أين جاءت كل بيانة

لكل سجل في قاعدة البيانات مصدر معروف ونسخة وبصمة. لا شيء مُولَّد، ولا شيء مُخمَّن.

## 1. السلسلة

```
حزمة npm منشورة (نسخة مثبّتة)
   ↓ قراءة الملف من القرص + SHA-256 للملف
تحليل (parse) بلا أي تعديل على النص
   ↓ SHA-256 لكل آية/ترجمة (مسافات موحّدة فقط)
تحقق (validate): أعداد، ترقيم، فجوات، تكرار، حروف عربية، خرائط الأقسام
   ↓
استيراد في معاملة واحدة + نسخة Dataset (version + source_file_hash)
   ↓ إعادة حساب كل بصمة من النص المخزَّن ومقارنتها بالمصدر
verified
   ↓ اعتماد بشري (مطلوب)
published  ← لم يحدث بعد
```

## 3. ما لا يوجد في المصدر يبقى NULL

`bismillah` (نص البسملة) · `sajdah_type` (حكم السجدة) · `text_simple` ·
سيرة القارئ ودولته وتواريخه وصورته. لم يُملأ أي منها بالتخمين.

## 4. الأعمدة المشتقّة (وليست تعديلًا)

`search_text` و`search_skeleton` مشتقّان من النص للبحث فقط، موثّقان في
`docs/SOURCE_POLICY.md`، ولا يُعرضان ولا يُصدَّران. `raw_text` يبقى حرفيًا —
حتى المسافة الرفيعة U+2009 في 2:72 محفوظة، ولا يُطبَّق حتى تطبيع يونيكود.

## 5. التحقق المتكرر

```bash
npm run integrity          # 30 فحصًا آليًا (JSON)
npm run integrity:final    # 41 فحصًا نصيًا + إعادة حساب 6,236 بصمة
npm run verify             # إعادة تحقق مقابل المصدر
```
آخر نتيجة: PASS بلا أي discrepancy — `quran_api/reports/QURAN_FINAL_INTEGRITY.txt`.

## 6. سجل التدقيق

كل استيراد وكل اعتماد بشري وكل تسجيل ترخيص يكتب سطرًا في `quran.audit_logs`
(الفاعل، الحدث، الكيان، التفاصيل) — بلا أسرار وبلا نصوص محتوى.
