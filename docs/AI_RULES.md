# AI_RULES — قواعد الذكاء الاصطناعي في فلاح

المرجع الملزم: وثيقة v2 §4 و§17 والملحق (هـ)؛ التنفيذ: ADR-005 و`SKILL_REGISTRY.md`.

## المسموح
تنظيم المحتوى، اقتراح عنوان/وصف/تصميم/ترتيب/قالب/ألوان/وسوم، تلخيص محتوى **غير ديني**،
تحسين الصياغة الإدارية، ترجمة النصوص غير الشرعية، تحويل النص الموثق لصيغ نشر
(منشور/Thread/Caption) دون مساس بالنص الشرعي.

## الممنوع (SOURCE_LOCK — غير قابل للتعطيل)
اختراع أو تعديل آية/حديث/تخريج/درجة/تفسير/فتوى/حكم/فضيلة/وعيد/ثواب/مصدر،
أو نسبة قول للنبي ﷺ أو لعالم دون مصدر موثق. ترجمة AI للنص الشرعي ممنوعة.

## نصوص الرفض الموحدة (الملحق هـ — حرفية، لا تُعاد صياغتها)
- نص شرعي غير موجود: «لم أجد مصدرًا موثوقًا كافيًا للتحقق.»
- طلب فتوى/حكم: «هذا خارج نطاق المساعد. يمكنك الرجوع إلى جهة إفتاء معتمدة.»
- طلب تعديل نص شرعي: «لا يمكن تعديل النص الشرعي؛ يمكنني تعديل التصميم أو الصياغة المصاحبة فقط.»

## الإنفاذ التقني (أين يعيش في الكود)
1. حارس العميل قبل أي شبكة: `sourceLockRouter` (`features/ai/data/aiProvider.ts`).
2. System Prompt ثابت في دالة `ai-assistant` (لا يقبل تجاوزًا؛ دفاع Prompt Injection).
3. (قادم) Tool Calling + Output Guard خادميًا + تسجيل في `ai_requests/ai_logs`
   + Rate Limiting حسب الخطة.

## الاختبارات الحمراء الإلزامية (v2 §33)
طلب حديث مختلق، محاولة Prompt Injection، طلب فتوى، طلب تعديل نص شرعي —
تعيش في `features/ai/assistant.test.ts` ويجب أن تبقى خضراء في CI.
