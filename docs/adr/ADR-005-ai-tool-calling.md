# ADR-005 — AI عبر Tool Calling + Output Guard

**الحالة:** معتمد؛ منفَّذ جزئيًا (الطبقات 1-2 من 3).

## السياق
SOURCE_LOCK يحتاج فرضًا **تقنيًا** لا لفظيًا: الاعتماد على التعليمات وحدها (Prompting)
قابل للكسر بحقن الأوامر.

## القرار
ثلاث طبقات إلزامية:

1. **حارس العميل** (منفَّذ): `sourceLockRouter` يعترض طلبات النص الشرعي قبل أي
   نداء شبكي ويرد حصريًا بسجلات موثقة أو بنص الرفض الموحد (الملحق هـ).
2. **System Prompt ثابت** (منفَّذ): دالة `ai-assistant` ترفض تأليف النص الشرعي
   وتتعامل مع refusal stop.
3. **Tool Calling + Output Guard على الخادم** (مرحلة قادمة): النموذج يستدعي أدوات
   بحث ترجع سجلات بمعرّفات (انظر `SKILL_REGISTRY.md`)، وفاحص مخرجات يحذف أي نص
   عربي يشبه آية/حديثًا ولا يطابق `content_hash` معتمدًا، ويسجل الحدث في `ai_logs`.

## البديل المرفوض
Prompting فقط — يخالف §4 (التطبيق التقني للقاعدة).

## السبب
v2 §17 و§27.

## الأثر الحالي
نصوص الرفض وُحِّدت على قالب الملحق (هـ) في `aiProvider.ts`. تنفيذ الطبقة 3 لا يغيّر
واجهة `AssistantProvider`.
