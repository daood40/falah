# ADR-004 — معالجة الفيديو بـ FFmpeg في Worker خلفي

**الحالة:** معتمد؛ المنفَّذ اليوم هو مسار المعاينة/التصدير على الجهاز، والـWorker ضمن مرحلة 3.

## السياق
التصدير الحالي يتم على الجهاز: `renderEngine` يرسم الإطارات و`MediaRecorder` يسجل
WebM مع مزج التلاوة عبر WebAudio (`features/video/data/videoRenderer.ts`).
هذا يكفي للمقاطع القصيرة لكنه محدود بالبطارية وقيود المتصفح وصيَغ الإخراج (لا MP4 موثوق).

## القرار
- الإنتاج النهائي (MP4/H.264، مدد أطول، دقات أعلى) في **Worker خلفي** (`workers/video/`)
  يستهلك طابور مهام، مع Idempotency لكل مهمة.
- يبقى مسار الجهاز الحالي **معاينةً وFallback** للمقاطع القصيرة وعند غياب الاتصال —
  لا يُحذف.

## البديل المرفوض
FFmpeg داخل الجهاز فقط (بما فيه ffmpeg.wasm): استهلاك بطارية، حدود ذاكرة الويب،
وتعارض مع أهداف الأداء (v2 §32).

## السبب
v2 §16 و§27.

## الأثر الحالي
لا تغيير على الكود الحالي؛ `videoRenderer` codec-agnostic أصلًا والـWorker يُضاف كطبقة فوقه.
