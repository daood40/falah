## 3. ما استوردناه منهم إلى فلاح (v1.6.0) — بشرط توافقه مع SOURCE_LOCK ونطاق v2

| ميزتهم | تنفيذ فلاح |
|---|---|
| التقويم الهجري | تاريخ هجري (أم القرى) في الرئيسية — Intl على الجهاز، **صفر شبكة وصفر موقع جغرافي** |
| التذكير بالمناسبات | شريط «مناسبات قادمة» بعدّ تنازلي (رمضان، العيدان، عرفة، عاشوراء، رأس السنة) موجه لصانع المحتوى: «جهّز محتوى المناسبة من الآن» |
| المحتوى اليومي | «حديث اليوم» من البذرة الموثقة (إضافة لآية اليوم الموجودة) — يفتح مباشرة في المصمم |
| العلامات المرجعية (Bookmarks/Khatmah) | «آياتي المحفوظة»: نجمة على أي آية، وشريحة رجوع فوري في صفحة الإنشاء |
| المسبحة | صفحة «السبحة»: عدّاد دائري بأهداف 33/34/100، اهتزاز، إجمالي يومي محفوظ محليًا؛ الألفاظ الواردة حرفيًا في النص القرآني المعتمد تحمل مرجع الآية |
| نسخ الآية للمشاركة | زر «نسخ النص مع المرجع» — النص + [السورة والآية] + اسم المصدر (احترام النسبة) |

**خارج النطاق عمدًا** (قرار وثيقة v2 §7): مواقيت الصلاة والقبلة — مؤجلة، ليست جوهر منتج صناعة المحتوى.

## 4. حل مشاكلهم = ضمانات فلاح المعمارية

| مشكلتهم | ضمان فلاح (مفروض بالكود لا بالوعود) |
|---|---|
| بيع بيانات الموقع | **لا يُطلب إذن موقع إطلاقًا**؛ لا SDK إعلانات ولا تتبع؛ CSP تمنع أي اتصال خارج قائمة سماح معلنة |
| الإعلانات | صفر إعلانات — لا مكتبة إعلانات في الاعتماديات أصلًا |
| Offline مكسور | Offline-first حقيقي: القرآن كاملًا مدمج ومفهرس محليًا، Service Worker مختبر |
| Paywall على المقدس | كل النص الشرعي مجاني دائمًا؛ الاشتراكات (مستقبلًا) على أدوات الإنتاج فقط |
| الحجم الضخم | تقسيم لكل سورة + تحميل كسول؛ الحزمة الرئيسية 373KB (gzip 124KB) |
| نصوص غير موثوقة | SOURCE_LOCK: بصمة SHA-256 لكل نص، بوابة نشر تتحقق قبل كل تصدير |
| إزعاج الإشعارات | إشعارات لأفعال المستخدم فقط، بلا حملات |

## 5. تميّز فلاح الذي لا يملكه أحد منهم

هم **تطبيقات قراءة واستهلاك**؛ فلاح **استوديو صناعة ونشر**: محرر طبقات + قوالب المستخدم + فيديو تلاوة + جدولة ونشر تلقائي + AI مقيد بالمصادر — مع كل مزايا القراءة اليومية أعلاه. لا يوجد تطبيق في القائمة يجمع الاثنين.
