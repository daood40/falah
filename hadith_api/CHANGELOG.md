## [1.2.0] — 2026-09-17 — تدقيق ما قبل الإطلاق (274,881 فحصًا) وإصدار التصحيح V2

### أُضيف
* منظومة تدقيق (`npm run audit`): سبع عائلات فحص — بيانات، قاعدة بيانات، API،
  أمن، مشروع/عقد، Flutter، وحزمة الاختبارات — كل فحص أمرٌ مستقل على كائن مختلف
  (سجل، منفذ، دور، حمولة، ملف). الدليل: `reports/FINAL_QA_AUDIT.txt`.
* بيئة Staging حقيقية (`npm run staging:up`): قاعدة مستعادة من نسخة احتياطية،
  خادم بعملية مستقلة على منفذ خاص، والاختبارات تناديه عبر HTTP من خارج الخادم.
* اختبارات انحدار لكل عيب وُجد: `tests/audit-regressions.test.ts` (16 اختبارًا).
* بوابة CI جديدة: `npm run audit -- --only=db,project`.

### تغيّر
* **إصدار بيانات جديد `JAMI-KAMIL-1437-V2` — 15,959 سجلًا**، بصمة
  `ab6bf4d5…db8df9`. سطران زخرفيان («• • •» في ج11/ص195 وج11/ص278) كانا قد
  استُوردا كحديثين بلا نص؛ النص المقفل لا يُعدَّل في مكانه، فالتصحيح إصدار جديد
  مستورد من نفس ملفات المصدر ببصماتها نفسها، و V1 محفوظ `superseded` ببصمته.
  لم يُمَس حرف واحد من نص أي حديث.
* البحث: عمود مولَّد `raw_text_normalized` بفهرس trigram + عدّ في مرور واحد —
  «من» من ‎3.0s إلى ‎0.46s بنفس النتائج تمامًا.
* التحقق من المدخلات: ترميز نسبة مئوية فاسد ‎→ 400، حرف تحكم ‎→ 422، عدد خارج
  مدى int4 ‎→ 422 (كانت كلها 500).
* `corpus.content_license_confirmed()` صارت `security definer` كي يقرأ دور
  anon العرض العام دون فتح `app_settings`.
* عملاء Dart/TypeScript: تغطية كاملة لعقد الـOpenAPI (طبعات، مجموعات، مجلدات،
  تحقق متقاطع، إصدارات البيانات).

## [1.1.0] — 2026-09-17 — التدقيق النهائي والتسليم المستقل

### أُضيف
* تدقيق الطبعة (`npm run edition:audit`): مانيفست لكل مجلد (بصمة، حجم، صفحات،
  سجلات) ومطابقة الملفات بقاعدة البيانات مجلدًا مجلدًا — 12/12 PASS.
* سلسلة السلامة (`npm run chain:verify`): RAW → DATABASE → API → EXPORT،
  بصمة واحدة عند كل محطة — 400/400 عند كل محطة.
* تصدير المجموعة (`npm run export`) بمانيفست يحمل بصمة الملف وبصمة المجموعة.
* تقرير التكرارات (`npm run duplicates`) — تقرير فقط، بلا حذف أو دمج.
* فحص أمني (`npm run security:scan`) واختبار نسخ واسترجاع فعلي (`npm run backup:test`).
* بوابة محتوى ثانية مستقلة: `PUBLIC_DATA_ENABLED`.
* كاش العميل بقواعد البصمة (‏`HadithCache`) وحارس عنوان الإنتاج في Flutter.
* وثائق: `API_USAGE.md` (cURL/JS/TS/Dart/Flutter/Python/PHP) · `SECURITY.md` ·
  `LICENSE` · هذا الملف.

### تغيّر
* المجلد `hadith-api/` → `hadith_api/` استعدادًا لفصله إلى مستودع مستقل.

## [1.0.0] — 2026-09-17 — عقد Falah العملي

### أُضيف
* استجابة من مستويين: قائمة مختصرة وتفصيل قياسي، والأجزاء الثقيلة بـ`?include=`.
* `/hadiths/random` · `/hadiths/daily` (حتمي) · أجزاء الحديث الخمسة ·
  `/sources/{id}` · `/books/{id}/chapters` · `/version` · `/datasets`.
* ختم المجموعة ببصمة SHA-256 واحدة، وعرض `verification_state` بثلاث طبقات.
* عميل Dart رسمي بنماذج مكتوبة الأنواع، ودليل `FALAH_INTEGRATION.md`.

### أُصلح
* **2,212 نسبة تخريج خاطئة**: أسماء كتب ترد أيضًا في السند («أنس بن مالك»،
  «علي بن مسلم»، «عن الحميدي») كانت تُحتسب استشهادًا. القاعدة صارت تقرأ الموضع
  لا مجرد الورود؛ الروابط 29,146 ← 26,934، وتأييد التخريج 75.30% ← 77.01%.
